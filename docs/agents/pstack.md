# pstack

pstack skills (architect, arena, how, why, reflect, interrogate, code-review, unslop, …) run from the user skill install.

Per-role models live in `~/.config/pstack/models.md`. Every role is `inherit-parent` on this machine: this host does not expose a confirmed model inventory for delegates, so workers use the parent chat model. The file never decides whether a skill can run.

Do not vendor pstack into this repo. Do not add pstack files to a product PR for RongleCat/grok-app.
